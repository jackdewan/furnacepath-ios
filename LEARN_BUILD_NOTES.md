## Backend

The course-backed server (`server.py.learn-draft` installed as `server.py`) is live on port 3011 via the `furnacepath` systemd user service. The pre-learn server is preserved at `server.py.pre-learn-backup`.

### Course serving

`/data/course.json` returns the 14-unit course from `~/furnacepath/content/course/unit-*.json` (445 questions total: 58 kept, 85 rewritten, 302 new). `/data/questions.json` returns the union: course questions first, then active Tutor-generated questions whose IDs are absent from the course (lesson 0 overlay).

### Migration (`course-rewritten-v1`)

Applied on live DB at service restart. The migration:
- Adopted the single NULL `user_id` progress row (zero XP, zero state) into `legacy-owner` by archiving it in `legacy_progress_adoption` and deleting the duplicate.
- Added `course_mastery` column to `answers`; set it to 0 on 14 historical answers for the 85 rewritten question IDs (preserves history, excludes from mastery calculations).
- Removed 5 review queue entries for rewritten IDs.
- Recomputed `unit_progress.lessons_completed` for all users against the new 14-unit mapping.
- Idempotent: a marker in `schema_migrations` prevents re-application.

## iOS

### Learn flow

Merged `learn-step` into `main` as a fast-forward. The learn flow implements:

- **Phase chip**: LEARN (accent-ink on accent-tint) during teaching cards, CHECK (ink-label on white) at the transition, DONE (green-ink on green-tint) at recap.
- **Card meter**: segmented capsule track under the eyebrow, accent-filled for cards reached.
- **Three card treatments**: idea (plain white card), worked example / shop-floor anchor (accent-tint panel with 4px accent spine, "ON THE SHOP FLOOR" label), common misconception (danger-tint panel with danger spine, "COMMON MISCONCEPTION" label, correction below in green-ink).
- **Transition screen**: green check disc, "Now check it" headline, ramp card with Define/Recognize/Apply/Judge counts, "+10 XP for every correct answer".
- **Recap screen**: "Lesson complete" header, correct/total and XP, recap card with accent spine and lesson's recap text.
- **Path**: 14 units from `/data/course.json`, all lessons tappable (nothing locked), full-row hit target via `.contentShape(Rectangle())`.
- **Course model**: `Course`, `CourseUnit`, `CourseLesson`, `TeachingCard`, `CourseQuestion` structs; `CourseQuestion.asQuestion()` bridges to the existing `Question` type.

## Caveats

- Claim remains DRY-RUN only (`CLAIM_ENABLED = False`). The endpoint returns a preview; no data is transferred.
- The `api/complete-round` fixture in Verification.swift returns a static SaveResult; it does not validate answer correctness.
- White text on the accent button fill is 3.49:1 — inherited from the normative token table, not introduced by the learn step. Flagged in the spec's self-critique.
- The card meter and header track show the same progress during the learn phase. The spec notes the track is the redundant one if one must go.
- At accessibility text sizes the teaching cards should scroll under the pinned Continue button; this needs real-device testing.
